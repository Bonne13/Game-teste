# Jogar no Windows — v0.11.0

[Baixar ProximaEstrela-Windows-x64.zip](https://github.com/Bonne13/Game-teste/raw/refs/heads/main/downloads/ProximaEstrela-Windows-x64.zip)

Extraia o ZIP e abra `ProximaEstrela-Windows-x64.exe`. No Windows 10/11 com Microsoft Edge, o jogo abre em uma janela de aplicativo. Sem Edge, usa o navegador padrão. Os arquivos ficam dentro do executável e funcionam offline. Mantenha o iniciador aberto enquanto joga.

O pacote foi compilado para Windows x64; a execução em um Windows físico ainda precisa ser validada. Esta versão usa a mesma base WebGL da edição web, com janela de aplicativo; não é uma versão em motor nativo independente.

O APK desta pasta é de uma versão anterior. Para testar a atualização no celular, use a versão web.
